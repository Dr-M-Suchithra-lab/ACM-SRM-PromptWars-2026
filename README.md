## 📁 What to Submit
Create your own folder inside `students/`:

```
students/
└── <RegisterNumber>-<Name>/
    ├── README.md      ← required (template below)
    ├── src/           ← your full project code
    ├── prompts.md     ← key prompts you used to build it
    └── screenshots/   ← app screenshots
```



Example: `students/RA2311003010123-Priya/`

### Your README.md must include
1. **Problem statement** (as given)
2. **Your solution** – what it does, in 3–5 lines
3. **Tools used** – e.g. Gemini, Google Antigravity
4. **How to run it**
5. **Demo link** – deployed app or video (Drive / YouTube unlisted)
6. **Key prompts** – the most important prompts that built your solution

---

## 🚀 How to Submit (GitHub website, no Git commands needed)

1. **Accept the invite** to the Dr-M-Suchithra-lab organization (check your email).
2. Open this repo → click the **main** dropdown (top left) → type `<RegisterNumber>-<Name>` → **Create branch**.
3. Make sure you are **on your branch** → **Add file → Upload files**.
4. Drag your project files in. To place them in your folder, first create `students/<RegisterNumber>-<Name>/README.md` using **Add file → Create new file**, then upload the rest into that folder.
5. Click **Commit changes**.
6. Click **Compare & pull request** → title: `Submission – <RegisterNumber> – <Name>` → **Create pull request**.

✅ **Your submission time = the time you create the pull request.**
To update before the deadline, upload to the **same branch**; your pull request updates automatically.

---

## 📌 Rules
- **Solo event:** your own work only.
- Work **only inside your own folder**. Do not edit or delete others' files.
- ⚠️ **Never upload API keys** (Gemini or any other), passwords, or `.env` files. Remove keys before uploading. Exposed keys can be misused.
- One pull request per student.
- Copied or plagiarised work will be rejected.

---

## ✔️ Review
- **Approved** → merged into the official event record
- **Changes requested** → update your branch
- **Closed** → not accepted (reason in comments)
