# Fair Shift

Fair Shift is a cross-device platform built with React and a central server that connects shift workers on mobile with employers on laptops.

## Overview

- **Accessibility**: Supports English, Tamil, and Hindi with a built-in text-to-speech speaker button for low-literacy workers.
- **Shift & Compensation**: Tracks attendance and uses an integrated mathematical reasoning model to accurately calculate overtime and pay.
- **Site Tracking**: Integrated OpenStreetMap for viewing job location sites on mobile.
- **Worker Well-being & Safety**: Features anonymous mood tracking and a safe case-reporting tool that generates unique case codes for privacy.
- **Device Optimization**: Mobile-first console for employees and desktop-first console for employers.

## UI Design Advantage

Most competing projects rely on standard AI-wrapper templates with vibrant purple backgrounds and low-contrast text that are easily identifiable as generic AI outputs and impractical for real-world use. Fair Shift uses a clean, seamless, and professional UI focused on high contrast, large buttons, and practical accessibility for both employers and employees.
